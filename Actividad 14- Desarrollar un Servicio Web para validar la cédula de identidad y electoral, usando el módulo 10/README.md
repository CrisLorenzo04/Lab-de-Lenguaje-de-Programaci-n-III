# Validador de Cédula Dominicana

## Descripción

Aplicación web (Servicio Web) que permite ingresar una cédula de identidad y electoral dominicana y valida su autenticidad matemática utilizando el algoritmo oficial del Módulo 10 establecido por la JCE.

## Requisitos Cumplidos

1. Permite ingresar una cédula dominicana (con o sin guiones).
2. Valida la cédula usando el algoritmo del Módulo 10 en JavaScript.
3. Muestra un mensaje claro indicando si es válida o inválida.
4. Lenguaje: HTML5 y JavaScript (Frontend puro).
5. Uso de Inteligencia Artificial: Se utilizó un asistente de IA (Qwen) para:
   - Desglosar y comprender la lógica matemática del algoritmo Módulo 10 paso a paso.
     -Consultar por errores encontrados durante el desarrollo.

## Cómo ejecutar

Simplemente abra el archivo `validador-cedula.html` en cualquier navegador web moderno.
